# RAJVEER — Architectural & Design Decisions

This document tracks all design and implementation decisions made in accordance with the project specification.

## 1. Authentication & Session Strategy
- **Mechanism:** Signed JWT using `jose` library (HS256) stored in an HTTP-only, Secure, SameSite=Lax cookie (`rajveer_session`).
- **Owner Session:** 7 days expiration. Holds `{ role: 'owner', ownerId: string, username: string }`.
- **Customer Session:** 30 days expiration. Holds `{ role: 'customer', customerId: string, username: string, name: string }`.
- **Direct-link Session:** Created on access to `/c/<token>` after verifying customer is active and in `link` access mode.
- **PIN Verification:** Customer username and 4-digit PIN verified against `customers.pin_hash` using `bcryptjs`.
- **Direct Link Generation:** Generated via `crypto.randomBytes(18).toString('base64url')` yielding a 24-character URL-safe token.
- **Rate Limiting:** Managed in the `login_attempts` table. 5 failed login attempts within 15 minutes for any given identifier (username or client IP) trigger a 15-minute lockout with a polite notice.

## 2. Database & Data Isolation
- **Client Access:** Zero direct client access to Supabase. All reads/writes happen via Server Actions and Route Handlers using the Supabase Service Role key.
- **Row Level Security (RLS):** Enabled on all tables (`owners`, `customers`, `bills`, `receipts`, `login_attempts`, `settings`) with `revoke all` from `anon` and `authenticated`.
- **Customer Scoping:** In all customer portal queries and customer-accessible route handlers, `customer_id` is strictly extracted from the verified session JWT (`session.customerId`) and never accepted from query parameters or request body.
- **Sequence Generation:** `bill_no` is auto-generated by the database sequence `bill_no_seq` starting at 1, read-only in the UI, displayed with zero-padding `#0001`.
- **Cascading Deletion:** Customer deletion requires typing the exact customer name to confirm. All bills and receipts are deleted via foreign key `ON DELETE CASCADE`.

## 3. Design System & Theming
- **Palette:**
  - Page Background: `#FFFFFF`
  - Soft Yellow Background: `#FFFBEB`
  - Gold Accent: `#F5B400`
  - Gold Accent Hover: `#D99A00`
  - Gold Accent Soft: `#FFF3C4`
  - Text Primary: `#0A0A0A`
  - Text Muted: `#6B6B6B`
  - Border: `#EFE7C8`
  - Success (Received / Advance): `#15803D`
  - Danger (Pending / Overdue): `#B91C1C`
- **Typography:** `Inter` for crisp body copy and `Poppins` for bold headers and numeric values.
- **Dark Mode:** Explicitly omitted per requirements. Light theme only.
- **Mobile-first Layout:** 375px width base. On screens < 640px, tables transform into stacked cards to eliminate horizontal scroll. Sticky bottom floating action button (+) for quick entries, and bottom navigation bar on mobile vs. left sidebar on desktop.
- **Touch Targets:** At least 44px for buttons, input font sizes >= 16px to prevent iOS auto-zoom, and numeric keypad (`inputMode="numeric"`, `inputMode="decimal"`) on all currency, PIN, and gold weight fields.

## 4. Number, Date & Communication Formatting
- **Currency:** Indian number grouping formatted with `₹` (e.g. `₹3,80,372.00`). Negative pending amounts are displayed as "Advance" in green.
- **Gold Weight:** Formatted to 2 decimal places with `g` suffix (e.g. `35.17 g`), while preserving 3 decimal precision in storage.
- **Timezone:** `Asia/Kolkata` used for all date calculations and display format `dd MMM yyyy` (e.g. `07 Aug 2026`).
- **Autosuggestions:** Add Bill dialog extracts unique item descriptions from past bills (up to 20 suggestions) to accelerate entry of common jobs (e.g., "Gold Ring 22k", "Necklace Repair", "Bangles").
- **WhatsApp Share:** Formatted with bullet points, balances, and personalized links using `wa.me/<phone>?text=...` with automatic Indian phone normalization (`91` prefix for 10-digit numbers).

## 5. Exports & Backups
- **Excel Export (`/api/export/excel`):** Built server-side using `exceljs` with black headers, white text, yellow total row, frozen headers, and formatted currency/date cells.
- **PDF Statements (`/api/export/pdf`):** Generated using `jspdf` + `jspdf-autotable` with luxury black/gold header, customer summary, and dual bills/receipts tables.
- **6-Monthly Backup Reminder (`/api/export/backup`):** Checks `settings.last_backup_at` against `owners.created_at` + interval. Delivers a sticky yellow banner and daily login modal when due. Generates a ZIP archive containing `Rajveer_All_Data.xlsx` and individual `<Customer Name>.xlsx` workbooks.
